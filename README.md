Los archivos en docs/mockups son referencias visuales y funcionales aprobadas.

Cuando exista un mockup específico de un módulo, debe revisarse antes de modificar su Frontend.

Los mockups no sustituyen el contrato funcional ni el DDL. La implementación debe mantener coherencia visual sin copiar mecánicamente elementos obsoletos o datos ficticios.
